# ISTE 422 Final Exam

## What does this app do?
This app takes data from the .csv files and converts them into output(json) and processed files.

## Node Version
You need node version 22.15.0

## Steps to Build Project
- npm install
- npm run 

## Dependencies Required
- chokidar
- csv
- dotenv
- jest

## How to use the Container
- run the command: docker-compose up
